Context Optimization Strategies Applied

1. Use /compact Often

Implementation: The condensed CLAUDE.md reduces baseline context from ~70KB to ~8KB, minimizing the need for frequent manual compaction.

Benefit: AI agents start with 88% more context budget available for actual implementation work rather than specification parsing.

2. Context Optimizer Patterns

Front-loaded critical rules: Non-negotiable invariants appear in the first 50 lines, ensuring AI sees constraints before making decisions.

Scannable structure: Headers indicate scan time (30-second, 1-minute, 2-minute) so AI can quickly locate information.

Essential-first ordering: Tech stack, commands, and safety defaults appear before detailed workflows.

3. The CLAUDE.md Trick

Micro-file with strict rules: CLAUDE.md kept under 200 lines (~172 lines achieved) while preserving all critical architectural constraints.

Project conventions at a glance: Repository structure, layering rule, decision flow, and coding standards visible without scrolling.

Reference-driven depth: Section references (§1-§33) let AI dive deep only when needed, not by default.

Design Principles

Scannable Hierarchy

Each section header indicates how long it takes to scan (30-second, 1-minute, 2-minute), helping AI prioritize what to read based on context budget.

No Prose Bloat

Eliminated "as mentioned above," "it's important to note," and similar filler. Every line carries essential information.

Visual Separators

Used horizontal rules (---) sparingly to mark major section boundaries, making structure clear at a glance.

Inline Code Formatting

Technical terms like `NO_ACTION`, `decision_id`, `packages/domain/` formatted as code to distinguish them from prose.

Grouped Lists

Related items grouped with subheadings (Data & Consent, Decision Safety) rather than flat bullet lists.

Reference Format

Section references use consistent format "§X — Description" making them easy to grep and follow.

The new CLAUDE.md gives AI agents everything they need to start coding in CartGuard AI without loading the full 1,004-line specification. It preserves all critical constraints while saving 88% of baseline context, leaving more room for actual implementation work, file reads, and tool outputs.
